# Co-Passage Source Code

This directory contains the entire source code for the Co-Passage application, which is structured as a Vite project.

## Layout

- `src/`: Contains the frontend React application code (components, hooks, pages, etc.).
- `public/`: Public static assets.
- `supabase/`: Supabase Edge Functions, database schema, or migrations.
- `vite.config.ts`: Vite configuration.
- `package.json`: Project dependencies and scripts.
- `.env.example`: Environment variable template.

## Getting Started

1. Copy `.env.example` to `.env` and fill in the required environment variables.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
